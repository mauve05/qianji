❓ 项目列表 · 操作帮助

页面结构

  • 项目分三个选项卡显示：我的项目（我创建的）、授权项目（我被授权的，绿色标识）、其他项目（仅管理员可见，按班级分组）
  • 项目按 全校 → 年段 → 班级 分组；📌 置顶的排在最前（仅对本人生效）
  • 从班级进入时（班级上下文）直接显示该班项目，新建项目自动归属该班级

新建项目

  • ＋ 新建项目：选择范围（班级 / 年段 / 全校 / 学科，按权限显示）、登记模式、评价模式（笑脸 / 十分 / 数值 / 优良 / 星级 / 评语 / 答题 / 自定义模式）；登记模式在上，选「举牌」时评价模式自动固定为「答题」（A/B/C/D）不可改，选「答题卡」时评价模式固定为「数值」不可改，选其他登记模式则释放
  • 登记模式：单次（仅登记一次）登记一次即完成；多次按「项次」登记，可自行增减项次；打卡每天可打卡一次（记录打卡日期）；举牌每生一张黑白图案举牌卡，把所选答案边（A/B/C/D）转到正上方即可识别；答题卡按「题次」多题涂卡识别（先设计答题卡模板再拍照/上传识别，得分自动写入）
  • 补登记阈值 / 登记后自动锁定：默认关闭，勾选后设置时长（天/时/分/秒）；本班首位登记超过阈值后的登记记为「补登记」，学生登记超过锁定时长后记录被锁定（禁止取消/修改点评）；勾选后时长全为 0 同样视为关闭

工具栏弹窗（班级上下文）

  • 📣 喊话：班级喊话弹窗——快捷播报（全班）/ 选人播报 / 图片发送 / 功能设置选项卡，客户端链接在右上「🔗 客户端链接」弹窗内复制，可勾选「需反馈」让班级端确认收到后才开始自动最小化，底部可开启班级端反向喊话教师端
  • ⭐ 积分：课堂积分弹窗——快速加减分、抽选学生、积分流水与汇总分析、积分项设置
  • 🔗 查询：公开查询弹窗——班级级总开关 + 查询链接复制 + 按项目允许查询

卡片操作（卡片右上角 ▾）

  • 进入登记：打开项目操作页点序号登记；扫码登记：用摄像头扫学生二维码登记
  • 答题卡类型项目在列表上的按钮是「扫描识别」（进 omr_scan.html 拍照/上传识别涂卡），其他类型是「扫码登记」（进 scan.html 扫学生二维码）
  • 查看报表：进入该项目的登记统计；查询链接：设置学生 / 家长公开查询（班级级总开关 + 按项目允许）
  • 编辑 / 置顶 / 办结：编辑项目设置；办结 = 归档隐藏到「已办结」选项卡，可随时恢复
  • 删除：软删除进回收站（登记数据保留可恢复）；彻底删除在回收站中操作，不可恢复
