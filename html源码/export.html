统计报表

❓ 统计报表中心 · 操作帮助

📈 数据总览

  • KPI 卡片：班级总数 / 学生总数 / 项目总数 / 登记·打卡人次 / 评价人次 / 登记人次÷学生数
  • 四张图表（ECharts）：各班级登记人次与登记率（柱+线）、每日动态（打卡/一次性登记堆叠柱，超40天可缩放拖动）、评价内容分布（环形 Top 10）、年段对比（登记率）
  • 图表随顶部「导出时间范围」实时联动；每张图右上角 📷 可保存为图片；口径与导出一致（一次性按登记时间、打卡按打卡日期过滤）

📤 报表导出（Tab 分区）

  • 🏫 班级报表：单班三按钮 —— 登记矩阵（学生 × 项目矩阵 Excel，每项目一张表，打卡项目按日期展开 ✓）/ 全部项目明细（是否登记 / 登记时间 / 评价内容 三张分表）/ 全部学生（每位学生一张表）
  • 📦 批量导出：勾选多个班级 + 报表类型 → 打包 ZIP 下载（每个班级一个独立 Excel 工作簿 + 导出说明.txt）；仅一个文件时直接下载工作簿

📅 导出时间范围

  • 选择开始 / 结束日期后，图表与所有导出按钮自动按该范围统计；留空 = 全部时间
  • 快捷按钮：本周（周一～周日）/ 上周 / 本月 / 全部时间；文件名自动附带范围后缀
  • 范围口径：一次性项目按「登记时间」落范围；打卡项目按「打卡日期」落范围；范围外的登记在该导出中按未登记计

📊 在线统计（默认折叠）

  • 点击班级按钮在弹窗中打开该班登记统计页（各项目登记情况、每日打卡、学生明细与图表，支持条形 / 折线 / 饼图切换）
  • 展开「学生登记统计」后可按学生查看各项目登记 / 评价 / 打卡天数明细，并支持导出该生登记情况（stats.html 学生统计页）
