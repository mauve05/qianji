> 教师个人使用的课堂作业登记 / 评价 / 统计系统。扫码即可登记作业完成情况并进行点评，支持打卡、多次登记、举牌、答题卡批改等多种模式，自带统计报表、公开查询、班级大屏、喊话与积分等功能。

自己创建班级和项目。

## 功能特性

- **多种登记模式**：仅登记一次 / 按日期打卡 / 多次登记（项次）/ 举牌模式（题次黑白卡）/ 答题卡（OMR 涂卡识别）
- **多样评价**：预设评价模式（笑脸、分数等）与自定义评价模式，评价历史完整留痕
- **扫码登记**：学生扫码即登记，支持普通 / 高清 / 超清三档摄像头清晰度，兼容「潜记 APP」二维码
- **答题卡批改**：内置答题卡设计器 + 摄像头批改识别，批改图可存服务器或浏览器本地
- **班级大屏**：座位表大屏展示，支持座位自动分组、班级码 / 个人码二维码打印
- **统计报表**：数据总览图表（ECharts）、班级 / 全校 / 教师提交率报表，多格式导出（Excel / CSV / ZIP 批量打包）
- **喊话**：教师端向班级大屏发送文字 / 语音喊话，支持反向喊话
- **积分**：加减分规则、积分兑换礼品、积分流水

## 环境要求

> 由于调用摄像头必须使用 WEB 服务环境，Win10 及以上双击 `启动网站.bat` 即可直接使用（零依赖，仅监听本机 localhost），也可将全部文件部署到自己可控的服务器 / 内网环境使用。
>
> ⚠️ **隐私提醒**：本系统会录入学生个人信息，请只部署在自己可控的环境。请勿上传到他人运营的第三方在线托管站点——第三方理论上可篡改页面脚本，导致学生信息泄露。需要多设备 / 多账号使用时，请选用本仓库的 PHP 服务版。
- 浏览器：Chrome / Edge 等现代浏览器（扫码、录音、答题卡批改依赖摄像头 / 麦克风权限）

## 摄像头 / 麦克风说明

扫码、录音、答题卡批改依赖摄像头 / 麦克风，浏览器仅允许 **HTTPS** 或 **localhost** 页面访问。局域网其他电脑访问时请使用 HTTPS，例如 `https://电脑IP`；否则页面会明确提示无法启动摄像头。

## 数据备份

- 系统不会上传任何数据到外部服务器，全部数据保存在**当前浏览器**的 IndexedDB 中（库名 `qj_local`）。
- 换浏览器 / 换电脑数据不互通；**清除浏览器数据会一并删除全部登记数据**，请谨慎操作。
- 请定期用首页的「备份数据」导出备份文件留存，需要时用「📂 恢复数据」导入还原；忘记密码时系统也会先自动导出备份再清空重设。

## 安全说明

- 所有数据自托管，不依赖第三方云服务。
