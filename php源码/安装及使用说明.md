# 潜记 · 二维码作业登记系统

> 教师个人使用的课堂作业登记 / 评价 / 统计系统。扫码即可登记作业完成情况并进行点评，支持打卡、多次登记、举牌、答题卡批改等多种模式，自带统计报表、公开查询、班级大屏、喊话与积分等功能。

可注册多个账号，每个账号都是独立的个人空间，自己创建班级和项目，可授权其他账号协作管理。

## 功能特性

- **多种登记模式**：仅登记一次 / 按日期打卡 / 多次登记（项次）/ 举牌模式（题次黑白卡）/ 答题卡（OMR 涂卡识别）
- **多样评价**：预设评价模式（笑脸、分数等）与自定义评价模式，评价历史完整留痕
- **扫码登记**：学生扫码即登记，支持普通 / 高清 / 超清三档摄像头清晰度，兼容「潜记 APP」二维码
- **答题卡批改**：内置答题卡设计器 + 摄像头批改识别，批改图可存服务器或浏览器本地
- **班级大屏**：座位表大屏展示，支持座位自动分组、班级码 / 个人码二维码打印
- **统计报表**：数据总览图表（ECharts）、班级 / 全校 / 教师提交率报表，多格式导出（Excel / CSV / ZIP 批量打包）
- **公开查询**：家长免登录查询孩子登记与评价情况（班级码 + 编号 + 姓名三重验证）
- **班级协作**：通过 8 位班级授权码将其他账号加入班级协作管理
- **喊话**：教师端向班级大屏发送文字 / 语音喊话，支持反向喊话
- **积分**：加减分规则、积分兑换礼品、积分流水（敏感操作需验证登录密码）

## 环境要求

- PHP **7.2+**（需启用 `mysqli`、`mbstring` 扩展；`zip` 扩展可选，缺失时批量导出自动降级为合并工作簿）
- MySQL **5.7+**
- 浏览器：Chrome / Edge 等现代浏览器（扫码、录音、答题卡批改依赖摄像头 / 麦克风权限）

## 安装步骤

1. 将整个 目录部署到 PHP 站点目录（或本地用内置服务器运行）：
   ```bash
   php -S 127.0.0.1:8080 -t /path/to/qjphp
   ```
2. 浏览器访问 `http://你的地址/install.php`，按安装向导操作：
   - 页面自动完成环境检测（PHP 版本、mysqli、mbstring、目录写权限）；
   - 填写数据库连接信息（主机 / 用户名 / 密码 / 数据库名），可点「测试数据库连接」验证，不存在的数据库会自动创建；
   - 设置管理员用户名与密码；
   - 点击「开始安装」自动建库建表、写入初始数据，并**自动生成 `includes/db_config.php`**，无需手工复制模板。
   > `db_config.php` 含真实密码，已在 `.gitignore` 中排除，请勿提交到仓库。
   > 向导幂等可重复执行（不删除现有数据）；已安装状态下会显示提示，可强制重新配置。
3. 安装完成后使用你设置的管理员账号登录（建议登录后立即在「个人中心」修改密码）。
4. 其他账号可在登录页自主注册（受后台「允许注册」开关控制），或在后台由管理员手工添加。

## 摄像头 / 麦克风说明

扫码、录音、答题卡批改依赖摄像头 / 麦克风，浏览器仅允许 **HTTPS** 或 **localhost** 页面访问。局域网其他电脑访问时请使用 HTTPS，例如 `https://电脑IP`；否则页面会明确提示无法启动摄像头。

## 数据备份

- 数据库数据存于 MySQL，可用 `mysqldump` 定期备份 `qj_registration` 库。
- `uploads/` 目录存放喊话语音、答题卡批改图等上传文件，备份时一并复制。
- 系统不会上传任何数据到外部服务器，全部数据都在你自己的主机上。

## 目录结构

```
qjphp/
├── index.php            # 登录入口
├── install.php          # 安装向导（环境检测 + 数据库/管理员表单 + 建库建表 + 自动生成 db_config.php）
├── install.sql          # 建表 SQL（供手动导入）
├── classes.php          # 班级管理（学生名单 / 座位表 / 二维码）
├── projects.php         # 项目（作业）管理
├── project_view.php     # 项目详情（登记矩阵 / 评价 / 统计）
├── scan.php             # 扫码登记
├── omr_designer.php     # 答题卡设计器
├── omr_scan.php         # 答题卡批改
├── stats.php            # 班级总览统计
├── export.php           # 统计报表中心（图表 + 导出）
├── query.php            # 家长公开查询
├── profile.php          # 个人中心
├── admin.php            # 后台管理（注册开关 / 用户管理）
├── api.php              # 前后端接口
├── includes/            # 公共函数库与数据库配置
├── assets/              # 前端静态资源（CSS / JS / 字体等）
└── uploads/             # 运行时上传目录（自动创建，勿提交仓库）
```

## 安全说明

- 所有数据自托管，不依赖第三方云服务。
- 密码使用 bcrypt 哈希存储；积分导入 / 导出 / 清空等敏感操作需验证登录密码。
- 公开查询页需班级码 + 学籍号 + 姓名三重匹配，且仅对开启了「允许查询」的项目生效。
