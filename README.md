> 教师个人使用的课堂作业登记 / 评价 / 统计系统。每位学生一张专属二维码（贴在作业本上），教师批改时用摄像头「扫一下」即完成登记，可同步给出评价，并衍生出打卡、举牌答题、OMR 答题卡批改、家长公开查询、班级大屏喊话、课堂积分等场景。

**官网**：<https://ziyuan.yunketang100.com/qj> ｜ **微信公众号**：潜紫阳光

## ✨ 功能特性

- **多种登记模式**：仅登记一次 / 按日期打卡 / 多次登记（项次）/ 答题 / 举牌模式（题次黑白图案卡四选一）/ 答题卡（OMR 涂卡识别）
- **多样评价**：预设评价模式（笑脸、十分、数值、优良、对错、星级、评语、答题 A-D）与自定义评价模式，评价历史完整留痕
- **扫码登记**：摄像头连续扫码，支持多码同识，兼容「潜记 APP」二维码（班级名单码 `bjdl` / 个人码 `djxh+编号`）
- **答题卡批改**：可视化拖拽答题卡设计器 + 摄像头批改识别（四角定位、透视矫正、涂黑率采样，全流程本地计算，图片不上传）
- **举牌答题卡**：每人一张 6×6 黑白图案卡，学生把所选选项转到正上方，摄像头识别朝向即得全班答案
- **班级大屏**：座位表大屏展示，支持座位自动分组、拖拽调位，班级码 / 个人码二维码批量打印（PDF / Word）
- **统计报表**：数据总览图表（ECharts）、班级 / 项目 / 学生多视图，多格式导出（Excel / CSV / ZIP 批量打包、答题卡成绩四分表）
- **公开查询**：家长免登录查询孩子登记与评价情况（班级码 + 编号 + 姓名三重验证，可按项目开关）
- **班级协作**：通过 8 位班级授权码邀请其他账号协作管理（管理 / 创建 / 登记 / 只读四级权限）
- **喊话**：教师端向班级大屏发送文字字幕 / 跑马灯 / TTS 语音 / 真人录音，支持反向喊话、强制全屏
- **积分**：个人 / 小组积分项、一键加减、随机抽选加分、自动积分规则（登记成功、答对答错、OMR 每题等）、礼品兑换、积分流水（敏感操作需验证登录密码）

## 📦 两个版本，怎么选？

本仓库包含同一产品的两种独立部署形态，功能界面同源，按需选用：

| | `html源码/` **单机版** | `php源码/` **服务版** |
|---|---|---|
| 适用场景 | 一位老师、一台电脑 | 多账号、多设备、家校场景 |
| 运行环境 | 双击 `.bat` 即用，零安装 | PHP 7.2+ / MySQL 5.7+ 主机 |
| 数据存储 | 当前浏览器的 IndexedDB | 服务器 MySQL 数据库 |
| 账号体系 | 本机密码门禁（单账号） | 多账号注册 / 班级协作授权 |
| 独有功能 | — | 公开查询（家长）、班级协作、喊话真人录音存服务器、后台管理、模拟登录 |
| 数据安全边界 | 换浏览器 / 换电脑不互通；清浏览器数据会清空全部数据 | 数据集中存在服务器，`mysqldump` 可备份 |

> ⚠️ 单机版数据存在**浏览器**里：换浏览器、换电脑数据不互通，清除浏览器数据 = 删除全部登记数据。需要多设备或长期集中保存时，请用服务版。

## 🚀 快速开始

### 单机版（`html源码/`）

1. Windows 10 及以上：解压后进入 `html源码/`，双击 **`启动网站.bat`**。
   - 零依赖：调用系统自带 PowerShell 启动本地静态服务器，仅监听 localhost（无防火墙弹窗）；
   - 端口从 8765 起自动尝试（8765–8774），启动后自动打开浏览器。
2. 首次访问设置一个本机密码（仅存本机，作为隐私门禁），即可开始使用。
3. 也可将整个目录部署到**自己可控的**任意静态服务器 / 内网服务器，用现代浏览器（Chrome / Edge）访问。

> ⚠️ **隐私提醒**：请勿将系统上传到他人运营的第三方在线托管站点——第三方理论上可篡改页面脚本，导致学生信息泄露。请只部署在自己可控的环境。

### 服务版（`php源码/`）

环境要求：PHP **7.2+**（需启用 `mysqli`、`mbstring` 扩展；`zip` 扩展可选，缺失时批量导出自动降级为合并工作簿）、MySQL **5.7+**。无框架、无 Composer 依赖。

1. 将 `php源码/` 整个目录部署到 PHP 站点（宝塔 / Nginx / Apache 均可），本地试用可运行：
   ```bash
   php -S 127.0.0.1:8080 -t /path/to/php源码
   ```
2. 浏览器访问 `http://你的地址/install.php`，按向导操作：
   - 自动环境检测（PHP 版本、mysqli、mbstring、目录写权限）；
   - 填写数据库连接信息，可先「测试数据库连接」，不存在的数据库会自动创建；
   - 设置管理员账号密码，点击「开始安装」自动建库建表并生成 `includes/db_config.php`；
   - 向导幂等可重复执行，不会删除现有数据。
3. 安装完成后，**建议删除 `install.php`**，然后用管理员账号登录即可。
4. 其他账号可在登录页自主注册（受后台「允许注册」开关控制）。

<details>
<summary>手动导入 SQL 安装（备选，不推荐）</summary>

直接导入 `install.sql` 也可完成建库建表（默认库名 `qj_registration_single`），随后访问 `install.php` 完成管理员创建。若仅导入 SQL 不跑向导，系统内置默认账号 **`admin` / `123456`**——**登录后请立即在「个人中心」修改密码**。推荐一律走 `install.php` 向导，由自己设置管理员密码。
</details>

## 📖 典型使用流程

1. **建班**：新建班级 → 手动添加或从 Excel 粘贴导入学生名单；
2. **打码**：进入二维码打印页，生成全班个人码表格（可导出 PDF / Word），裁剪后贴到作业本封面；也可打印班级导入码，其他老师/其他端扫码即可导入整班名单；
3. **建项目**：创建作业项目，选择登记模式（一次 / 打卡 / 项次 / 答题 / 举牌 / 答题卡）与评价模式；
4. **登记**：批改时打开「扫码登记」摄像头连扫，或用项目页的数字网格点选登记，随手给出笑脸 / 分数 / 评语；举牌课用举牌卡一扫全班答案；测验课用答题卡设计器出卡、摄像头批改自动判分；
5. **统计**：统计页看班级总览 / 单项目 / 单学生三视图；报表中心按时间范围导出 Excel / CSV；
6. **家校**：开启「允许查询」的项目，家长用班级码 + 学生编号 + 姓名免登录查询；教室大屏常驻喊话客户端展示字幕 / 语音。

## 🏗️ 架构一览

两版均为**原生 JavaScript + 单个手写样式表**，无前端框架、无构建步骤；第三方库全部本地化（见[第三方库声明](THIRD-PARTY-NOTICES.md)），**零 CDN 外链，可完全离线运行**。

```text
服务版                          单机版
浏览器（原生 JS）                浏览器（同一套页面）
   │  fetch('api.php')             │  fetch('api.php')
   ▼                               ▼
api.php 单一入口（4100+ 行）      Service Worker (http 环境)
   │  按 type 分发百余个动作  ◄──┤  fetch 补丁 (file:// 环境)
   ▼                               ▼
MySQL（30 张表）                 js/api_local.js 接口仿真层
   bcrypt / 预处理语句             ▼
                                 IndexedDB「qj_local」
                                 （26 个 store 模拟 MySQL 表）
```

单机版最有意思的设计：页面代码几乎原封不动地从 PHP 版移植——所有 `fetch('api.php')` 请求由 Service Worker（或 `file://` 下的 fetch 补丁）拦截，交给 `js/api_impl_a/b/c.js` 在 IndexedDB 上按与 PHP 版相同的接口语义执行。换后端不改前端，这是它能保持双形态同源演进的根基。

数据模型与接口对照可参考：`php源码/install.sql`（30 张表，逐字段中文注释）、`php源码/api.php`、`html源码/js/db.js`（store 清单与表结构一一对应）。

## 🔒 安全说明与已知限制

**已落实的安全措施**

- 全部数据自托管，不依赖任何第三方云服务；密码 bcrypt（`password_hash`）存储；
- 登录 / 改密 / 模拟登录均 `session_regenerate_id`；30 天免登令牌随机生成、SHA-256 哈希入库、HttpOnly Cookie；
- 文件上传做魔数校验 + 随机文件名 + `realpath` 前缀校验，防路径穿越；
- 公开查询需班级码 + 编号 + 姓名三重匹配且受项目级开关控制；喊话客户端凭 32 位随机令牌访问。

**如实披露的已知限制**（自部署内网使用风险可控，公网部署请知悉）

- 「忘记密码」仅凭手机号 + 姓名即可重置（无短信验证码）。教师手机号对同事 / 学生近乎公开，公网部署建议关闭该入口、改由管理员在后台重置；
- 后台提供「模拟登录」功能（仅超级管理员可用，全程留痕），用于排查用户问题；
- 导出的 CSV / Excel 未对 `=`、`+`、`@` 开头的单元格做公式注入转义，打开来历不明的导出文件时请勿点击「启用」外部内容；
- 单机版的「密码」只存本机 IndexedDB，是防误触的隐私门禁，不是加密；
- `install.php` 安装完成后不会自我锁定，请按提示手动删除。

## ❓ 常见问题

<details>
<summary>双击「启动网站.bat」后没打开浏览器 / 端口被占？</summary>

`webserver.ps1` 会从 8765 起依次尝试 10 个端口（8765–8774），全部被占时窗口会提示。关掉占用程序重试即可；命令行手动运行 `powershell -ExecutionPolicy Bypass -File webserver.ps1` 可看到详细日志。
</details>

<details>
<summary>摄像头 / 麦克风无法启动？</summary>

浏览器只允许 **HTTPS** 或 **localhost** 页面访问摄像头 / 麦克风。单机版默认走 localhost 不受影响；服务版从局域网其他设备访问时需配置 HTTPS（如 `https://192.168.x.x`）。
</details>

<details>
<summary>单机版数据存在哪？怎么备份？会丢吗？</summary>

存在当前浏览器 profile 的 IndexedDB（库名 `qj_local`）。**清除浏览器数据 / 重装浏览器会全部丢失**。请定期用首页的「备份数据」导出备份文件（JSON，含全部班级 / 学生 / 登记 / 评价数据），需要时用「📂 恢复数据」导入还原。换浏览器或换电脑数据不互通——需要迁移时请改用服务版。
</details>

<details>
<summary>忘记密码怎么办？</summary>

单机版：密码无法找回。登录页点「忘记密码？」会**先自动导出一份备份文件**，然后清空本机数据重新设置账号密码，再用顶部「📂 恢复数据」导入备份即可找回数据。服务版：管理员在「后台管理 → 用户管理」中重置，或使用「忘记密码」页（见上方安全限制）。
</details>

<details>
<summary>如何升级到新版本？</summary>

覆盖部署新文件即可，数据库结构由 `install.php` 幂等补齐（不删数据）；单机版刷新页面后 Service Worker 自动更新。升级前建议先备份数据（服务版 `mysqldump` + `uploads/` 目录）。
</details>
